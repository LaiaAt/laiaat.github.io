# BityVoz Uploader

BityVoz Uploader es una aplicación de uso personal creada por el desarrollador para automatizar la generación y publicación de videos cortos (YouTube Shorts) en el canal de YouTube "BITYVOZ".

La aplicación utiliza inteligencia artificial para generar guiones y locución en español, y publica los videos automáticamente en la cuenta de YouTube del propio desarrollador mediante la API de YouTube.

Esta app es de uso exclusivamente personal y no comparte, vende ni distribuye datos de terceros.
